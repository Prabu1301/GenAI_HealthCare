## 🧠 GenAI_HealthCare

A zero-cost, multi-platform healthcare documentation pipeline powered by Gen AI. This project integrates audio input, backend processing, and frontend visualization to streamline clinical workflows.

### 📁 Repository Structure

- `audio_files/` – Contains recorded `.mp3` files for transcription and processing  
- `backend/` – Python-based backend logic for transcription, schema validation, and correction workflows  
- `frontend/` – UI components for displaying and editing transcribed reports  
- `dummy/` – Placeholder or test data for development and validation  
- `requirements.txt` – Python dependencies for backend execution  
- `test_backend_endpoint.py` – Script to validate backend API endpoints

### 🚀 Features

- Audio-to-text transcription using Gen AI
- Schema validation and correction workflows
- Frontend interface for report editing
- Backend API integration with authentication
- Designed for Railway/GitHub deployment

### 🛠️ Setup

```bash
# Clone the repo
git clone https://github.com/Prabu1301/GenAI_HealthCare.git
cd GenAI_HealthCare

# Install dependencies
pip install -r requirements.txt

# Run backend tests
python test_backend_endpoint.py
```
